Vendredi 0.2.0 adds cases, ANSI X12 and a new desktop: a welcome screen, guided setup and the comforts of a native app.

### Cases

- A case is a partner scenario: the rules that answer its messages, the documents and scripts they use, samples to try it with and the replies it should produce. Each partner answers with its active case; switch it on the **Cases** page or with `vendredi case use`.
- Thirteen starter cases cover confirming, rejecting, answering late, never acknowledging, failing over HTTP, duplicate deliveries and malformed replies, for EDIFACT and X12.
- Import cases from a folder, a JSON file or an `https://` URL with **Import cases…** or `vendredi case import`. Imports are checked in full and previewed before anything is written.
- `vendredi case test` and **Run checks** send each sample in a scratch workspace and compare the replies with the expected ones. **Record expected replies** saves what a case sends today as its expected result.

### ANSI X12

- Partners can exchange X12: `ISA`/`GS` envelopes, 997 or 999 group acknowledgements and optional `TA1`, with delimiters read from each inbound `ISA`. Count and control-number problems are reported with their byte offsets.

### The desktop

- **First launch** shows a welcome screen: try the demo, create a workspace in a folder you choose, or open one. Later launches reopen the last workspace.
- **Guided setup** describes a new partner in three steps, and the **Getting started** steps walk through a first exchange and a failure.
- **Native behaviour:** a macOS menu bar, keyboard shortcuts (⌘1–⌘5, ⌘F, ⌘N, ⌘O, ⌘S, ⇧⌘S), file pickers, drag and drop to send a document or import a case, and the window and last page remembered. The desktop follows the system's light or dark appearance and supports screen readers.
- **Feedback:** confirmations appear briefly in the corner, and removing a case, rule, sample or partner can be undone. Common errors are explained with what to do next.
- **Editors:** the script editor highlights JavaScript, checks it as you type and can try a script on the selected message without sending anything. Documents show what each segment and field means.
- **Help** opens the guide and release notes, and **Report a Problem** prepares a report you can read and edit before sending.

### Upgrading from 0.1

Rules now live only in cases. A partner's `[[partners.rules]]` in `vendredi.toml` are ignored, and `vendredi case list` and headless mode warn about them. To keep them, create a case on the **Cases** page, add the same rules, make it active, and remove the rules from `vendredi.toml`. A partner without an active case only sends acknowledgements.
